RisuAI 비공식 가이드

직접 조립해서 쓰는 AI 채팅 프론트엔드 가이드북

💡
RisuAI가 처음이신가요?
RisuAI는 앱스토어에서 다운받아 가입만 하면 바로 쓸 수 있는 '완성된 채팅 앱'이 아닙니다. 이 문서는 처음 접하는 분들이 어려운 개념을 쉽게 이해하고 나만의 완벽한 대화 환경을 세팅할 수 있도록 돕는 비공식 기록입니다.

1. 플랫폼 vs 프론트엔드 (RisuAI란?)

RisuAI를 이해하려면 먼저 '일반 채팅 플랫폼'과 '프론트엔드'의 차이를 알아야 합니다. 둘 다 "AI 캐릭터와 채팅한다"는 목적은 같지만, 작동 방식이 완전히 다릅니다.

🍔 일반 채팅 플랫폼 = '프랜차이즈 식당'

식당에 가면 메뉴(AI 모델)가 이미 정해져 있습니다. 우리는 요리를 할 필요 없이 돈만 내고(앱만 켜고) 바로 먹을 수 있어 아주 편리합니다. 하지만 메뉴를 내 마음대로 바꿀 수 없고, 식당의 엄격한 규칙을 무조건 따라야 합니다.

🍳 프론트엔드 (RisuAI) = '내 전용 주방'

RisuAI는 AI와 대화할 수 있는 '도구 화면(주방)'만 제공합니다. 대화를 만들어낼 실제 똑똑한 두뇌(AI 모델)는 내가 직접 외부에서 가져와서 연결해야 합니다.

처음엔 요리법(API 세팅 등)을 배워야 해서 어렵고 귀찮지만, 내 입맛에 맞는 최고급 재료를 직접 가져와서 100% 내 마음대로 세팅할 수 있는 압도적인 자유도를 가집니다.

비교 항목 일반 채팅 플랫폼 프론트엔드 (RisuAI)
AI 모델 선택 앱에서 제공하는 모델만 사용 가능 원하는 AI(GPT, Claude 등)를 자유롭게 연결
세세한 설정 대부분 숨겨져 있거나 제한적임 프롬프트, 메모리 등 100% 직접 수정 가능
비용 월 정액제 또는 앱 내 재화 결제 API 결제, 혹은 구글 크레딧으로 무료 이용 가능
진입 장벽 앱 설치 후 즉시 사용 가능 (매우 쉬움) API 발급 등 초기 세팅 필요 (어려움)

2. 상세 가이드 (핵심 요소)

세부적인 설명이 필요한 항목을 펼쳐서 확인하세요.

▶ 설치 & API 연결

리수는 앱 설치가 필요하지 않아요. 크롬, 삼성 브라우저 등 웹사이트로 리수가 이용 가능합니다. 가장 먼저 우리 달글에서 주로 이용하는 것은 구글에서 제공하는 무료 크레딧을 구글 계정으로 받아 API를 연결하는 방식입니다. 이 방법은 초보자 가이드에 자세히 나와있으니 꼭 참고하세요.

▶ 캐릭터 카드 & 로어북 설계

캐릭터 카드는 이름, 설명, 성격, 첫 메시지, 예시 대화 같은 필드로 구성됩니다.

로어북은 특정 키워드가 등장할 때만 설정을 불러오고, depth와 우선순위로 언제 어떤 정보가 노출될지 세밀하게 조절해요. 카드는 캐릭터의 핵심만 담아 가볍게 유지하고, 방대한 설정은 로어북으로 확장하는 구조입니다.

여기에 작가의 노트를 더하면, 매 턴마다 AI에게 짧은 지시(말투 유지, 특정 행동 유도 등)를 얹어줄 수 있어요. 로어북이 캐릭터에게 "정보"를 주는 거라면, 작가의 노트는 AI에게 "지시"를 주는 느낌입니다.

▶ 하이파 메모리

하이파 메모리는 리수에서 쓸 수 있는 부가 기능입니다. 별도로 가입만 하면 평생 무료로 쓸 수 있어요. 컨텍스트를 넘어가는 과거의 내용을 자동으로 요약해서 저장해주기 때문에 캐릭터의 장기 기억이 확 늘어납니다.

▶ CSS / 스크립트 커스터마이징 (심화)

전혀 몰라도 채팅하는 데 아무 지장이 없습니다.

CSS는 화면의 테마 색상이나 채팅창 모양 등 내 마음대로 예쁘게 꾸미기 위한 기능이며, Lua/JS 스크립트는 한 단계 더 나아간 심화 기능입니다. 초보자일 때는 코드가 뭔지 아무것도 모르는 게 당연합니다. 이런 코드를 전혀 모른다고 해서 캐릭터와 채팅을 못 하거나 대화 퀄리티가 떨어지는 것은 절대 아니니 안심하셔도 됩니다!

3. 초보자를 위한 꿀팁 & Q&A

▶ 캐릭터 카드는 어디서 구하나요?

캐릭터 카드는 부속 달글의 '캐릭터 도감'에서 구하시거나, 재니터(Janitor), 렐름(Realm) 같은 외부 사이트에서 다운받으실 수 있습니다. 다운받은 이미지(PNG)를 RisuAI 화면에 그대로 드래그 앤 드롭하면 캐릭터가 바로 추가됩니다.

▶ 프롬프트(프리셋)는 꼭 그대로 써야 하나요?

처음에는 다른 사람들이 잘 깎아둔 프롬프트를 복사해서 그대로 쓰는 것을 추천합니다. 하지만 익숙해진다면, 프롬프트 역시 얼마든지 개인의 스타일로 마음껏 수정하고 달글 자료를 통해 다양하게 활용하셔도 괜찮습니다.

▶ 토큰(Token)이 도대체 뭔가요?

간단하게 말해 AI가 인식하는 '단어 수의 단위'이자 '기억력의 한계치'라고 생각하시면 됩니다.

예를 들어 AI의 가방(컨텍스트) 크기가 1,000토큰이라면, 대화가 길어져서 가방이 꽉 차는 순간 옛날 대화부터 밖으로 흘려버립니다(과거를 까먹음). 이 가방 크기를 효율적으로 쓰기 위해, 평소엔 숨겨뒀다 필요할 때만 꺼내보는 '로어북'을 쓰고, 꽉 찬 가방의 과거 기억을 압축해주는 '하이파 메모리'를 활용하는 것입니다.

▶ 리수 테마나 배경화면은 어떻게 바꾸나요?

RisuAI의 배경 이미지나 테마 등도 취향껏 꾸밀 수 있습니다. 직접 코드를 만질 필요 없이, 달글 자료실을 이용하시면 다른 금손 유저들이 공유해둔 예쁜 테마 자료들이 많으니 적극적으로 활용해 보세요.

이 문서는 RisuAI 공식 문서가 아니며, 제가 직접 ai와 함께 제작한 비공식 가이드입니다.
